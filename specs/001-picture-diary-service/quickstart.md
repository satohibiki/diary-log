# Quickstart: 絵日記公開サービス

実装の完了後に、機能が動作することを確認する手順。API は
[contracts/openapi.yaml](./contracts/openapi.yaml)、データは [data-model.md](./data-model.md) を参照する。

## 前提

- Node.js 26 LTS
- Docker
- Chrome(パスキーの手動確認には、加えて Firefox と Safari)

## セットアップ

```bash
npm ci
cp .env.example .env
docker compose up -d
npm run db:migrate
npm run dev
```

アプリは `http://localhost:5173`、開発用のメール確認画面は `http://localhost:8025` で開く。

## 品質ゲート

```bash
npm run verify
```

期待する結果: テスト、lint、型検査、脆弱性検査がすべて成功する。

## 検証シナリオ

E2E は `npm run test:e2e` で実行する。手動で確認する場合は次の順に行う。

| # | 手順 | 期待する結果 | 対応 |
|---|---|---|---|
| 1 | ID とメールアドレスで登録し、確認コードを入力してパスキーを作成する | ログイン状態になる。パスワードの入力欄がない | US1 |
| 2 | ログアウトし、ID とパスキーでログインする | ログインできる | US1 |
| 3 | 別のブラウザで ID を指定して復旧し、コードを入力する | 新しいパスキーの登録だけができ、完了後に通知メールが届く | US1 |
| 4 | 位置情報付きの画像で絵日記を作成する | 縦書きで表示され、取得した画像に位置情報がない | US2 |
| 5 | 記入中にタブを閉じて開き直す | 入力内容が復元される | US2 |
| 6 | 同じ日付で再度作成する | 既存の絵日記の編集へ案内される | US2 |
| 7 | カレンダーで前の月へ移動し、日付を選ぶ | その日の絵日記が開く | US3 |
| 8 | 登録直後の公開設定を確認する | 非公開である | US4 |
| 9 | 別の利用者でフォローを申請する | 承認前は絵日記が見えない | US5 |
| 10 | 承認して公開に切り替える | 一覧に絵日記が表示される | US5 |
| 11 | 非公開に切り替える | 5秒以内に相手から見えなくなる | US4 |
| 12 | 別の利用者として絵日記と画像の URL を直接開く | どちらも404になる | FR-035 |
| 13 | ブロックして再度の申請を試みる | 申請できない | US5 |
| 14 | エクスポートし、別のアカウントへインポートする | 全件が復元され、重複はスキップされる | FR-020 |
| 15 | 幅360pxで主要画面を開き、キーボードのみで操作する | 横スクロールなしで完了できる | SC-009、SC-010 |

## データの暗号化の確認

```bash
npm run verify:encryption
```

期待する結果: DB のダンプに、テストで使った本文とメールアドレスの平文が含まれない。
