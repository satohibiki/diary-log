# Quickstart: 手書きの絵日記帳風 UI の動作確認

## 前提

- 001 の開発環境の準備が済んでいる(README の「開発の準備」)。
- `.env` の `APP_ORIGIN` は `https://localhost:5173`(E2E は localhost で動く)。

```bash
docker compose up -d
npm run db:migrate
npm run dev
```

## 自動テスト

```bash
npm run verify                                  # 型検査、lint、単体と結合のテスト、npm audit、秘密情報の検査
npx playwright test e2e/diary-page.spec.ts      # ページの構成、罫線、書体、外部への通信、360px
npm run test:e2e                                # 全ブラウザで E2E 全体
```

期待する結果: すべて成功する。

## 手動での確認

| # | 手順 | 期待する結果 | 対応 |
|---|---|---|---|
| 1 | https://localhost:5173/diaries/new を開く | 上から絵の枠、日付欄「〇月 〇日(〇)」と天気欄、点線の罫線8行の文章欄が、角の丸い1枚のページに並ぶ。年はページの外に表示される | US1-1、FR-001、FR-003 |
| 2 | 縦長と横長の画像をそれぞれ選ぶ | 絵の枠からはみ出さず、ゆがまずに表示される | US1-2、FR-002 |
| 3 | 日付欄を押して日付を変える | 日付の選択が開き、選んだ日付が「〇月 〇日(〇)」で表示される。未来の日付は選べない | FR-005 |
| 4 | 日付欄の右隣の天気欄で「雨」を選ぶ | 「雨」だけが選ばれた状態になる | US1-6、FR-004 |
| 5 | 文章を入力し、改行を含めて9行以上書く | 文章は横書きで罫線の上に乗る。9行目で罫線が増えてページが伸び、文章欄の中でスクロールしない | US1-3〜5、FR-007、FR-009 |
| 6 | 400文字を入力する | 「残り 0 文字」と表示され、全文が見える | FR-008、Edge Cases |
| 7 | 保存する | 表示画面が、記入画面と同じページの見た目と折り返しで表示される | US2-1 |
| 8 | 001 の縦書きの画面で作った既存の絵日記を開く | 内容は変わらず、横書きのページで表示される | US2-3、FR-016 |
| 9 | フォロワーの立場で、みんなの日記と相手のページを開く | 同じページの見た目で表示される | US2-2、FR-015 |
| 10 | 開発者ツールの「ネットワーク」で通信を見る | 書体ファイルを含め、すべての通信が `localhost:5173` 宛て | FR-011、SC-006 |
| 11 | 端末をダークモードにする | ページは明るい紙の色のままで、文字と罫線が読める | FR-014 |
| 12 | ブラウザの拡大を200%にする | 文字と罫線の位置がずれず、内容が欠けない | Edge Cases |
| 13 | 幅360px(スマートフォン、または開発者ツールの端末表示)で 1、5、7 を行う | 横スクロールが起きない | US3-1、FR-017 |
| 14 | Chrome、Safari、Firefox、Edge で 7 を開く | 文章と日付欄が同じ手書き風の書体で表示される | US3-2、SC-003 |
| 15 | 文章に絵文字(😀)と記号(♪)を入れる | 欠けたり□になったりせず、代わりの書体で表示される | FR-012 |
| 16 | キーボードだけで、画像 → 日付 → 天気 → 文章 → 保存の順に操作する | すべて操作でき、各欄の名前が読み上げられる | FR-018 |
