# UI Contract: 絵日記のページ

API の変更はない。この文書では、画面の構成と、テストと支援技術が頼るアクセシビリティの約束を定める。

## 構成(上から順に)

```text
article.diary-page            … 角の丸い薄い灰色のカード
└─ div.diary-page__sheet      … 2px の黒い枠線の長方形
   ├─ figure.diary-page__picture   … 絵の枠(縦横比 4:3)
   ├─ div.diary-page__meta         … 日付欄と天気欄の行(左: 日付、右: 天気)
   │  ├─ div.diary-page__day
   │  └─ fieldset / div.diary-page__weather
   └─ div.diary-page__body         … 点線の罫線の文章欄(最小8行)
```

## 記入画面(新規作成、編集)

| 要素 | アクセシブルな名前 | 役割 | 備考 |
|---|---|---|---|
| 画像の選択 | 「絵(画像)」 | ファイルの入力欄 | 絵の枠の中に置く。JPEG、PNG、WebP、10MB まで(001 のまま) |
| 日付 | 「日付」 | 日付の入力欄 | 日付欄に重ねる。`max` は当日。編集時は変更できない |
| 天気 | グループ名「天気」 | ラジオボタン4つ: 「晴れ」「くもり」「雨」「雪」 | 日付欄と同じ行の右隣に置く |
| 文章 | 「文章」 | 複数行の入力欄 | `writing-mode: horizontal-tb`。高さは最小8行で、内容に合わせて罫線1行単位で伸びる |
| 残りの文字数 | — | 文章の入力欄の `aria-describedby` | 「残り N 文字」 |
| 保存 | 「保存する」 | ボタン | ページの下に置く |

キーボードの移動順は、画像 → 日付 → 天気 → 文章 → 保存。

## 表示画面(表示、みんなの日記、相手のページ)

| 要素 | アクセシブルな名前 | 備考 |
|---|---|---|
| ページ | `article` | ページの外の見出しに年と日付(例: 「2026年11月8日(日)」)を置く |
| 画像 | 「〇年〇月〇日(〇)の絵」 | 001 の代替テキストのまま |
| 日付欄 | — | 「11月 8日(日)」 |
| 天気欄 | — | 「天気 晴れ」(アイコンは `aria-hidden`) |
| 文章 | 「文章」 | 文字としてのみ表示する(HTML として解釈しない)。改行を保つ |

## 見た目の約束(テストで確かめる)

- **文章の向き**: 文章欄の `writing-mode` は `horizontal-tb`。
- **罫線と行**: 文章欄の `line-height` と罫線の間隔(`--rule-gap`)は同じ値。
- **行数**: 文章欄の高さは `--rule-gap` の8倍以上で、`--rule-gap` の整数倍。
- **罫線の位置**: 表示画面で、各行の文字の下端と罫線の位置の差は `--rule-gap` の1割以内。
- **書体**: 文章、日付欄、天気欄の書体の先頭は `"Klee One"`。
- **書体の配信元**: 書体ファイルは、アプリと同じオリジンから取得する。
- **360px**: 幅360pxで、文書の横幅が画面の幅を超えない。
- **配色**: ダークモードでも、ページの地の色と文字の色は変わらない。
