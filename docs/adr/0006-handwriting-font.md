# ADR-0006: 手書き風の書体と、その配信の方法

- **Status**: 採用
- **Date**: 2026-11-08

## 背景

002-handwritten-diary-ui で、絵日記を紙の絵日記帳に近いページで表示し、文章を手書きに近い書体で表示することにした
(FR-010)。書体の雰囲気は「ていねいなペン字風」とした(Clarifications Q2)。

端末に入っている書体は OS ごとに違い、手書き風の日本語の書体はほとんど入っていない。そのため、書体をサービスから
配信する必要がある。一方で、憲章 III(プライバシー)は、外部サービスに利用者の情報を送ることを禁じている。また、
CSP は `font-src 'self'` に限っている。

## 決定

- **書体**: Klee One(Fontworks、SIL Open Font License 1.1)の Regular(400)のみを使う。
- **入手の方法**: npm パッケージ `@fontsource/klee-one` を、バージョンを固定して依存関係に加える。
- **配信の方法**: Web アプリでパッケージの `400.css` を読み込み、Vite のビルドで書体ファイルをアプリと同じオリジンから
  配信する。CSP は変えない。
- **分割した配信**: パッケージは、文字の範囲ごとに 124 個の woff2 ファイルに分かれている(`unicode-range`)。
  ブラウザは表示する文字を含むファイルだけを取得する。一般的な日記の文章では約15ファイル、約280KB になる。
- **代わりの書体**: 読み込み中(`font-display: swap`)と、Klee One にない文字(絵文字など)は、端末の標準の日本語書体で
  表示する。行の高さは書体によらない固定の値にし、書体が切り替わっても罫線と行の位置が変わらないようにする。

## 検討した代替案

- **Google Fonts から読み込む**: 閲覧のたびに利用者の IP アドレスなどが Google に送られる。憲章 III と CSP に反するため
  不採用。
- **Zen Kurenaido(筆ペン風)、Yomogi(くだけた手書き風)**: 「ていねいなペン字」から離れ、長い文章が読みにくいため
  不採用。
- **書体ファイル全体(約1.9MB)を1つで配信する**: 初回の表示が遅くなり、SC-004(2秒以内)を満たしにくいため不採用。
- **太字(600)も入れる**: 使う場面がないため、YAGNI により入れない。

## 影響

- ビルドの成果物に、書体ファイル(woff2 と、古いブラウザ向けの woff)が加わる。利用者が取得するのは、表示する文字を
  含む woff2 ファイルだけである。
- 書体のライセンス(OFL)の条件として、書体を単体で販売しない。書体の名前を変えて配布しない。
- 書体のパッケージは実行するコードを含まない。依存関係の確認は、ほかのパッケージと同じく `npm audit` と lockfile の
  整合性ハッシュで行う。
